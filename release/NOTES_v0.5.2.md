# StratoCam v0.5.2

- Android launcher icon reduced by 15% with additional padding.
- Always-visible installation-folder selection, defaulting to `C:\Program Files\StratoCam`.
- Separate Desktop and Start Menu shortcut options.
- Installation progress bar, percentage, and destination path.
- Spanish and English installer support in this historical release; subsequent releases use English only.
- Automatic StratoCam webcam registration and safe webcam component updates.
- USB connection message inside the preview when no device is available.
- Physical Android display power-off during streaming on supported devices, with restoration when streaming ends.

Development release. The Windows installer is not Authenticode-signed; the APK is signed. See the README for requirements and limitations. Verify downloads with `SHA256SUMS.txt`.
