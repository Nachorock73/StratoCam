# StratoCam v0.5.2

- Icono Android un 15 % más pequeño, con margen adicional.
- Instalador con selección de carpeta siempre visible; ubicación predeterminada `C:\Program Files\StratoCam`.
- Opciones separadas para accesos directos al escritorio y al menú Inicio.
- Proceso visible con barra de progreso, porcentaje y carpeta de destino.
- Instalador disponible en español e inglés.
- Registro automático de la webcam StratoCam durante la instalación.
- Mensaje de conexión USB dentro de la preview cuando no hay dispositivo.
- Apagado físico del panel Android durante el stream, cuando el dispositivo lo admite; restauración al finalizar.

Descarga `StratoCam-Setup-v0.5.2.exe` para Windows 11 x64 y `StratoCam-Android-v0.5.2.apk` para Android. Sigue el asistente Windows y concede en Android los permisos de cámara y depuración USB. No necesitas comandos de registro.

Versión en desarrollo. El instalador Windows no tiene firma Authenticode; la APK está firmada. Consulta el README para requisitos y limitaciones. Verifica las descargas con `SHA256SUMS.txt`.
