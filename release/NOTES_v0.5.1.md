# StratoCam v0.5.1

- Automatic, mandatory webcam registration during installation, with error checking.
- StratoCam device name and migration from previous registrations.
- USB discovery retries when a phone takes time to become available.
- Installation and usage documentation.

Includes preview, camera controls, hardware-dependent 1080p30/4K30, original H.264 recording, and optional Windows AAC-LC audio at 48 kHz.

Install the Windows setup executable and Android APK, grant the required system permissions, and connect by USB. No webcam registration commands are required. OBS Studio 32.2.2 x64 integration is optional.

Development release. A visual issue when maximizing remains open, and compatibility depends on device capabilities. The Windows installer is not Authenticode-signed; the Android APK is signed. Verify downloads with `SHA256SUMS.txt`.
