# StratoCam v0.5.3

The installer and repository documentation now use English.

## Setup wizard

1. **Welcome** — click Next.
2. **Installation folder** — keep `C:\Program Files\StratoCam` or choose another location, then click Next.
3. **Shortcuts** — choose Desktop and Start Menu shortcuts, then click Install. OBS integration is installed automatically.
4. **Installing** — view the progress bar, percentage, and destination path. Webcam registration is automatic.
5. **Finish** — check or uncheck Launch StratoCam, then click Finish.

Download `StratoCam-Setup-v0.5.3.exe` for Windows 11 x64 and `StratoCam-Android-v0.5.3.apk` for Android. Camera permission and USB debugging authorization must be granted on Android. No registration commands are required.

This release preserves the reduced Android icon, USB connection placeholder, and supported-device display power control. It does not change recording, decoding, or camera controls.

Development release. The Windows installer is not Authenticode-signed; the APK is signed. See the README for requirements and limitations. Verify downloads with `SHA256SUMS.txt`.
